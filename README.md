# Age Calculator App

A responsive age calculator built with HTML, CSS, Tailwind CSS, and Vanilla JavaScript.

## Features

- Calculate age in years, months, and days
- Input validation
- Responsive design
- Interactive UI
- Mobile-friendly layout

## Technologies

- HTML5
- CSS3
- Tailwind CSS
- Vanilla JavaScript
